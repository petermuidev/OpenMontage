## What Claude Contributed

Claude Code was invoked through the configured Fireworks GLM-5.2 compatibility
route. Tool-enabled Claude Code requests returned repeated HTTP 409 errors, while
the underlying model endpoint remained healthy. The model therefore supplied a
bounded narrative direction through the direct text route; OpenMontage retained
composition and QA authority.

The first model draft invented an eastern shore, Chaweng, sand, palm fronds,
frangipani, and a longtail boat. Those details were rejected because the approved
sources did not prove them. The accepted 129-word script keeps only the original
premise: distance and quiet can reveal what constant noise hides.

## Corrections and Durable Lessons

1. A human-free villa derivative still contained old POC graphics. Human-free is
   not the same as clean-source-ready; inherited layouts create a competing visual
   system and must be rejected.
2. A clean representative frame did not prove a whole source interval. Dense CRV
   later exposed moving Chinese headings. Both contaminated villa intervals were
   removed rather than hidden with a broad mask.
3. Edge TTS produced two cues with a 50-millisecond overlap. The accepted caption
   contract sorts cues and clips each end time to the next start time before
   composition.
4. Technical render success was never treated as creative acceptance. Sparse
   contact sheets found the broad composition; dense interval review found the
   failures that controlled the final source selection.

## Reproduction Rule

Copy the decision contract, not this exact script or timeline. A new agent must
choose separately approved sources, write one original thesis, map every sentence
to visible support, normalize caption boundaries, run dense source and final
review, and obtain owner playback acceptance. Claude or another text agent may
plan inside the packet, but it may not alter claims, rights, sources, renderer,
publishing state, or acceptance status.
